# 猜詞作戰 — 中文 AI 語意聯想猜詞遊戲

靈感來自《魔鬼的詭計》中用 AI 判斷詞語聯想的遊戲，以及 Semantle / Contexto / 꼬맨틀 一類的猜詞遊戲。
玩家輸入任何中文詞，AI 會計算它和秘密答案的**語意相似度**，玩家靠分數和排名一步步逼近答案。

## 快速開始

遊戲是純靜態網頁，資料已經預先建置在 `web/data/`，不需要伺服器運算或 GPU：

```bash
cd web
python3 -m http.server 8000
# 打開 http://localhost:8000
```

> 要用 HTTP 伺服器開啟，直接雙擊 `index.html`（`file://`）時瀏覽器會阻擋讀取資料檔。
> 也可以把 `web/` 目錄直接部署到 GitHub Pages / Netlify / Cloudflare Pages。

## 遊戲模式

### 測試模式
揀（或隨機抽）一個題目，然後輸入任何詞，即時睇到佢同題目的相關度（0–100%）。可以隱藏題目俾其他人試。

### 隱藏詞對戰（參考《魔鬼的詭計：死亡重啟》第 5 日主賽「히든 워드」）
1. **派信封**：每人獲派 5 個一般名詞，難度組合人人一樣（2 易、2 中、1 難）；每回合從自己信封揀 1 個做隱藏詞。
   - **輕鬆**（預設）：只有具體名詞（動物、食物、物件、地方…）。
   - **標準**：「難」嗰格固定係 1 個抽象／情緒詞（`data/abstract_answers.txt`，例如夢想、快樂）。
2. **提示**：只可以用**名詞**，**專有名詞（人名、地名、品牌、作品）可以**；不可以包含成個隱藏詞，亦不可以係隱藏詞的一部分（例如隱藏詞「熊貓」，「熊」不可以，但「北極熊」可以）。
3. 提示**超過 95%** → 即時停止提示；出完 **10 個**都未超過 → AI 公開一個同隱藏詞最相似的詞。
4. **作答**：其他玩家秘密寫答案，同時公開。
5. **計分**：估中者得 1 分，該出題者回合即時結束；無人估中 → 出題者得 1／2／3 分（第 1／2／3 階段），最多 3 階段。
6. 1 或 2 回合（每回合每人出題一次），總分最高者勝。

> 規則參考自網上整理（namu.wiki），未必與節目完全一致；可在 `web/app.js` 頂部的常數調整。

### 詞庫與詞性
- **兩層詞庫**：核心詞庫約 3 萬詞（`vocab.json`，計排名／百分比用，保持分數標準一致）；
  擴充詞庫約 4 萬詞（`vocab_ext.json`，香港用語、較少用的詞、單字），開遊戲後喺背景載入。
- **香港用語**：`data/hk_words.txt`（茶餐廳、港鐵、八達通、行山…）；**口語對照**：`data/aliases.txt`（曱甴 → 蟑螂、士多啤梨 → 草莓）。
- **組合詞**：詞庫冇的詞會自動拆成已知部分再合成向量（菠蘿包 = 菠蘿 + 包、智能手機 = 智能 + 手機）。
- 英文唔分大小寫（wifi = WiFi）。實測三份常用詞清單（共 560 詞）覆蓋率 99–100%。
- 詞庫約 3 萬詞：jieba 常用詞 + `data/extra_words.txt`（常見專有名詞，例如周杰倫、麥當勞、維多利亞港）。
- 每個詞用 spaCy 中文詞性標注器分類為「一般名詞／專有名詞／其他」（放入 4 個句式投票，再參考 jieba 詞性）。
- **答案**：只用 `data/answers.txt` 人手揀選的一般名詞；**提示**：一般名詞或專有名詞都得。
- **難度**：建置時自動計算——如果答案最接近的提示詞「回頭看」時答案都排得好前（例如 醫生 ↔ 護士），
  玩家就容易由提示聯想到答案；再加上詞頻（常用詞較易），按三等分為易／中／難。

## AI 系統怎樣運作

```
[離線：tools/build_data.py]
jieba 常用詞（按詞頻、詞性過濾）
   ∩ spaCy zh_core_web_lg 詞向量（50 萬詞 × 300 維）
   → OpenCC 簡轉繁（保留簡體 / 台灣寫法作別名）
   → 正規化 → 扣除「垃圾網頁方向」（data/spam_seeds.txt）→ PCA 降到 128 維 → int8 量化
   → web/data/vocab.json（3 萬詞）+ vectors.bin（3.8 MB）+ answers.json

[瀏覽器：web/app.js]
選定答案 → 計算所有詞和答案的 cosine similarity → 排序得出排名
玩家輸入 → 查詞表 → 按排名換算成 0–100% 相關度
```

- **不需要訓練 LLM**：我們只需要一把「量度兩個詞意思有多接近」的尺，現成的詞向量（word embedding）已經足夠。
- **相似度**：先計算兩個詞向量的夾角餘弦值（cosine similarity），再排出詞庫中每個詞與題目的接近程度。
- **相關度 %**：按排名換算成 0–100%（第 1 名 99%、第 10 名 96%、第 100 名 90%、第 1000 名 78%、
  最後一名 0%），題目本身 100%。約最接近的 13 個詞會 ≥ 95%。換算表在 `web/app.js` 的 `PCT_ANCHORS`。

## 自訂 / 重新建置資料

1. 安裝依賴（見 `requirements.txt`），並下載 spaCy 中文模型。
2. 修改答案候選：`data/answers.txt`（每行一個繁體詞）。
3. 執行：

```bash
python tools/build_data.py \
  --spacy-vocab "$(python -c 'import zh_core_web_lg,os;d=os.path.dirname(zh_core_web_lg.__file__);print([os.path.join(d,x,"vocab") for x in os.listdir(d) if x.startswith("zh_core_web_lg-")][0])')"
```

常用參數：

| 參數 | 預設 | 說明 |
|---|---|---|
| `--size` | 30000 | 詞庫大小（越大越多詞可猜，檔案越大） |
| `--dim` | 128 | PCA 降維；`0` 表示保留原本 300 維（約 9 MB） |
| `--w2v` | — | 改用其他 word2vec 文字格式向量，例如 Tencent AI Lab Embedding、fastText `cc.zh.300.vec` |

## 設定

- **贊助按鈕**：在 `web/app.js` 頂部設定 `DONATE_URL`（例如 Buy Me a Coffee / Ko-fi / PayPal.me 連結）。
  留空時，按下會顯示「贊助連結即將推出」。

## 鳴謝

詞向量：spaCy `zh_core_web_lg`（MIT）· 詞庫：jieba（MIT）· 繁簡轉換：OpenCC（Apache 2.0）。
網頁介面刻意不顯示技術細節，鳴謝資料保留在此。

## 已知限制 / 下一步

- 詞向量用網絡爬蟲資料訓練，混有大量賭博及成人垃圾網頁，曾令「信封」接近「玄機、六合」、「護士」接近「少婦、裸體」。
  建置時會用 `data/spam_seeds.txt` 每組種子詞各找出 3 個「垃圾方向」並從所有向量扣除；
  如發現其他怪異聯想，可加種子詞（或新增一組 `## 名稱`）再重新建置。
- 題庫刻意避開政治、宗教等敏感題材。

- 詞向量用網絡文本訓練，部分聯想反映網絡用法（例如「蘋果」接近「手機」多過「香蕉」）。
- 粵語口語詞（嘢、睇、咗）覆蓋較弱，可以考慮加入粵語語料訓練的向量，或者人手補同義詞表。
- 可以改用句子向量模型（如 `bge-m3`）處理多字詞組，但需要後端或較大的前端模型。
- 可以加入節目式規則：團隊對戰、資訊不對稱、分數換籌碼、限時回合、網上即時對戰等。
